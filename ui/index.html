工具设置

控制智能体可用的工具：启用/关闭、访问权限（工作目录内/无限制）、输出截断限制与子代理策略。

启用与权限

「工作目录内」限制该工具只能访问当前工作目录中的路径；「无限制」允许访问任意路径。关闭的工具不会出现在模型可用的工具列表中。

截断限制

工具输出过长时自动截断（保留头尾，中间省略）。滑块控制最大字符数。

更改将在点击「保存」时统一生效，之前可随时取消。

子代理设置

子代理在独立上下文中运行，工具集继承自主会话。此处控制子代理可用的工具。

图像生成模型（qwen image 2.1）

image_generate 使用的模型（safetensors，精度自适应）。选项是 models/ 目录里的所有文件（含后缀），实时读取；留空表示不指定。LoRA 最多 2 个，按顺序应用（后一个叠加在前一个之上）。采样步数默认 25 步，采样器/调度器默认 euler + simple（与 released workflow 一致）。

视频生成模型（minimax h3）

video_generate 使用的模型（safetensors，精度自适应）。选项同样来自 models/ 目录。图像与视频的模型、LoRA 各自独立，互不混用。LoRA 最多 2 个，按顺序应用。采样步数默认 20 步，采样器/调度器默认 res_multistep + beta（H3 联合音视频）。

音乐生成模型（ace-step 1.5）

music_generate 使用的模型：DiT、文本/语义码 tower、音频 VAE，各自选择。选项同样是 models/ 目录里的所有文件。采样步数默认 50 步（与 ACE-Step-音乐生成.json 一致），采样器/调度器默认 euler + simple。

语音合成模型（breeze tts 2）

tts_speak 使用的模型：主检查点、音频编解码器、分词器 tokenizer.json，以及主模型与编解码器的 config.json（留空则读取权重旁边的 config.json）。只做「音色描述 → 语音」，不含声音克隆。

快捷键

点击绑定框后按下新的组合键即可重新绑定；按 Esc 取消。更改在点击「保存」后同步到服务器，重启不丢失。

「发送消息」「输入换行」决定输入框的按键行为；修改后点击「保存」生效，之前可随时取消。
